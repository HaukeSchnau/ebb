Ebb is on.

Ebb closes tabs you've stopped looking at and keeps them in an archive you can search.

  1. A tab starts aging when you leave it. Only time at the computer counts, so nights and weekends away don't.
  2. Some tabs never go. Pinned tabs, tabs in a group, tabs playing audio, and the tab you're on. Right-click any page to keep that tab or its whole site.
  3. Archived tabs are one search away. Click Ebb's toolbar icon, or type ebb and a space in the address bar.

Archive tabs after

You can change this later in the archive's settings. If Ebb notices you bringing back a lot of tabs, it will suggest a longer time.

Try it

Archive every tab in this window except this one and the protected ones. One click brings them all back.
